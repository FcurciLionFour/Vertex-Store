# Vertex Hogar — Home Static v4

V4 corrige la composición para parecerse más al mockup:

- Benefits strip flotante inmediatamente después del hero.
- Rail de categorías después de benefits.
- Productos destacados en 6 columnas.
- Banners promocionales debajo de productos, no al costado.
- Colecciones horizontales.
- Newsletter + mini benefits.
- Header y hero ajustados en escala.

Colocar esta carpeta dentro de `storefront/`, al mismo nivel que `src/`.

Ejemplo:
storefront/
  src/
  vertex-home-static-v4/
    home-static-v4.html
    home-static-v4.css

# Vertex Commerce — Design Package

Este ZIP contiene los assets visuales generados para Vertex Commerce / Vertex Hogar en este chat.

## Carpetas

- `00_referencias_originales/`: referencias iniciales compartidas en la conversación.
- `01_storefront_mockups/`: mockups de la tienda pública desktop.
- `02_customer_account_mockups/`: mockups de cuenta cliente, pedidos, wishlist y búsqueda.
- `03_design_system_boards/`: boards visuales del Design System: foundations, forms, commerce, navigation, feedback, icons, illustrations.
- `04_design_system_pdfs/`: PDFs del Design System / UI Spec.
- `05_admin_backoffice_mockups/`: mockups generados para backoffice/admin.
- `06_prompt_implementacion/`: prompt maestro para arrancar la implementación de la tienda pública Vertex Commerce V2.

## Regla principal

El diseño, colores, tokens, componentes y mockups incluidos acá son referencia obligatoria para la implementación.
No se deben improvisar layouts ni usar endpoints admin para el storefront público.
